# Venue anchor overview — Nature Computational Science / scientific machine learning

> **Note.** The section few-shot files (`abstract.md` … `discussion.md`) are not shipped in this release; the roster below describes the full calibration set.


The overview for this venue/field. It carries the **register**, the **how-to-read** conventions, the
**banned-vocabulary** note, and a **coverage roster**. The before→after examples live one-per-section
in the sibling files (`abstract.md`, `introduction.md`, `results.md`, `methods.md`, `discussion.md`);
each holds one or more papers' before→after pairs for that section. The machine-read contract (register,
vocabulary, conventions, acceptance bar) is `profile.md`; the `/review` panel kit is in `review/`.

## Register — Nature-family (broad-audience)

Accessible, significance-forward, narrative, and still rigorous. The main text leads with the question
and why it matters beyond the subfield, then the finding, then a non-specialist-legible mechanism;
heavy math and numerics move to Methods (at the end) and SI. This is the opposite emphasis from the
JCP/SciML anchor (`../../Journal-of-Computational-Physics/scientific-machine-learning/`): there the
prose is technical-first and equation-dense; here breadth and accessibility are first-class. See
`profile.md` for the fielded conventions (British spelling, ~150-200-word unstructured abstract,
numbered superscript references, Methods at the end).

## How to read each block

Each section file's entries follow the same shape used across venue-anchors:
- **After** = the paper's actual published prose, verbatim, de-LaTeX'd. This is the target.
- **Before** = the kind of weaker draft the polisher receives, carrying the same science.
- **Why** names the principle and tags the rubric/heuristic it teaches.

## Banned-vocabulary note

The global `references/banned-vocabulary.md` applies. The venue-acceptable exceptions for this register
(a moderate amount of genuine broad-reach framing, statistical "significant", technical "robust") are
in `profile.md` §vocabulary. Broad-significance framing is acceptable ONLY when the paper supports it;
unsupported reach reads as hype and should be flagged.
