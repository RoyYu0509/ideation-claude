# Supplementary Information

Heuristics and acceptance criteria for the Supplementary Information (evidence supporting main-text claims; consistent, reproducible, self-contained).

- The full rubric (the checkable acceptance criteria, with verdict + evidence per item) is in
  `references/rubric.md`. Read it before writing or scoring this section.
- Model passages and before/after pairs specific to this section live in `house-style/examples/venue-anchors/`.

## Writing register for this section

- **Every section opens with its trace.** The first sentence names which main-text claim, figure,
  theorem, or equation this section supports (e.g. "This section provides the derivation behind
  Theorem 2 in the main text"). Never assume the reader knows why a section exists.
- **Self-contained by default.** A reader who has not read the main text should be able to follow
  each SI section. Define all symbols on first use here; do not rely on main-text context.
- **No new conclusions.** Important findings belong in the main text. If a conclusion appears here
  that the main text did not set up, move it or update the main text.
