# Supplementary Information — rubric

Acceptance criteria for the SI. Verdict + evidence per item. The SI is **not a dump for material
that didn't fit the main text** — it provides supporting evidence, complete methods, derivations,
extra experiments, robustness checks, and reproducibility detail for the main-text claims.

## Suggested structure
Supplementary Methods → Theoretical Details / Mathematical Derivations → Extended Results →
Robustness / Ablation / Sensitivity → Additional Comparisons → Supplementary Tables and Figures →
Limitations and Notes.

## Items
1. **Traceability.** Each SI section states which main-text result, figure, theorem, or conclusion
   it supports.
2. **Consistency.** All symbols, numbering, and terminology match the main text exactly.
3. **Rigor.** Derivations are complete and rigorous.
4. **Reproducibility.** Experimental setups, hyperparameters, data processing, error metrics,
   statistical repeats, and baseline setups are reproducible.
5. **Self-contained captions.** Tables and figures have captions that stand on their own.
6. **No smuggled conclusions.** No important new conclusion appears that the main text did not set up.
7. **Honesty.** Assumptions, boundary conditions, failure cases, and limitations are stated plainly.

## Anti-patterns (flag)
- Content with no stated link to a main-text claim.
- Symbol / numbering / term drift from the main text.
- Incomplete derivations; non-reproducible setups.
- A major new claim introduced only in the SI.
